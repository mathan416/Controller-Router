# Emulator patch licensing

Controller Router's own Python code is provided under its MIT license. This
distribution also contains separately licensed patches against third-party
emulator sources:

- ArcEm: see `arcem/COPYING` and the source project's license notices.
- GSplus: see `gsplus/COPYING` and the source project's license notices.

The patches modify those programs and are distributed with their respective GPL
license texts. Emulator source, firmware, game media, and binaries are not included.
